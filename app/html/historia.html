1989 - El Inicio de la Web
Se redacta en el CERN la propuesta inicial que combinó hipertexto, el protocolo HTTP y direcciones URL, definiendo las bases de la red global
1991 - HTML y la Web 1.0
Se publica la primera especificación de HTML. Arranca la era de la Web 1.0: páginas estáticas y unidireccionales de "solo lectura", donde el usuario únicamente consumía texto e hipervínculos.
1995 - JavaScript
Brendan Eich desarrolla JavaScript en Netscape para dotar al navegador de capacidad de cómputo local, permitiendo las primeras interacciones dinámicas del lado del cliente.
1996 - CSS
El W3C publica la primera recomendación formal de hojas de estilo en cascada (CSS1), logrando separar por completo la estructura del documento de su diseño y presentación visual.
1998 - DOM
El W3C publica la especificación del DOM Nivel 1, permitiendo que lenguajes como JavaScript interactúen dinámicamente con la estructura en árbol de la página en memoria.
2004 - Web 2.0 y AJAX
Se consolida la Web 2.0 (plataformas sociales y colaborativas) junto con AJAX (XMLHttpRequest), permitiendo que el navegador envíe y reciba datos en segundo plano sin recargar la pantalla.
2014 - HTML5
El W3C y WHATWG lanzan HTML5, integrando semántica moderna, APIs nativas de almacenamiento local y soporte nativo para audio y video sin necesidad de plugins externos como Flash
2010 - Web 3.0
Surge la web semántica y descentralizada: protocolos abiertos, datos interconectados con significado semántico interpretable por máquinas, identidades digitales y WebAssembly.
2020 - Inteligencia Artificial en la Web
Auge e integración de modelos generativos y APIs de IA en el navegador, transformando los sitios web tradicionales en aplicaciones capaces de razonar, dialogar y generar contenido en tiempo real.
2024- Actualidad - La Web 4.0
Evolución hacia una red proactiva y omnipresente que conecta el Internet de las Cosas (IoT) con agentes de software autónomos que realizan tareas complejas, automatizaciones y toma de decisiones por el usuario.

Justificaciones:

1989:

El punto de partida de la web. Nació como una simple propuesta técnica en el CERN para resolver la necesidad personal de organizar protocolos y compartir información. Es impresionante cómo un proyecto académico sentó las bases universales de arquitectura y conectividad que cambiaron al mundo entero.

1998:

Convirtió una web puramente estática en un entorno vivo y dinámico. Al transformar las etiquetas en un árbol de objetos en memoria, permitió a JavaScript manipular interfaces en tiempo real y dio origen a los frameworks modernos.

2020-actualidad:

El hito más asombroso en la interacción humano-computadora. Antes todo se operaba manualmente con formularios rígidos; hoy, la integración de modelos de IA, agentes y APIs avanzadas permite automatizar procesos complejos y adaptar la experiencia al usuario al instante.
